# D-Dose

Calculadora de dose de fosfina (expurgo/silo/pilha) e diluição de produtos de desinsetização, para operadores em campo. Detalhes do projeto em [PROJETO.md](./PROJETO.md).

## Stack

React + TypeScript + Vite, Tailwind CSS, Supabase (Postgres + Auth).

## Rodando localmente

```bash
npm install
cp .env.example .env   # preencher com as chaves do projeto Supabase
npm run dev
```
